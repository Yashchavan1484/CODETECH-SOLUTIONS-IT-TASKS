# CODTECH AI Internship Tasks 🚀

This repository contains AI/ML tasks completed during my internship at **CODTECH IT SOLUTIONS**. Each task demonstrates practical implementation using Python and popular AI libraries.

---

## 📌 Tasks Overview

### **Task 1: Text Summarization Tool**

* Summarizes long articles into concise text using NLP.
* **Tech Used:** Python, NLTK / Transformers
* **Input:** Large text
* **Output:** Short summary

---

### **Task 2: Speech-to-Text System**

* Converts short audio clips into text.
* **Tech Used:** Python, SpeechRecognition / Wav2Vec
* **Input:** `.wav` audio file
* **Output:** Transcribed text

---

### **Task 3: Neural Style Transfer**

* Applies artistic styles from one image onto a content photograph.
* Uses a pre-trained Neural Style Transfer model from TensorFlow Hub.
* **Tech Used:** Python, TensorFlow, TensorFlow Hub, NumPy, Matplotlib
* **Input:**

  * `content.jpg` (photograph)
  * `style.jpg` (artistic style image)
* **Output:**

  * `output.png` (stylized image combining content and style)

---

### **Task 4: Text Generation Model**

* Generates coherent paragraphs based on user prompts.
* **Tech Used:** Python, GPT / LSTM, TensorFlow / PyTorch
* **Input:** User prompt
* **Output:** Generated text
